# 项目权限

本文档描述 OpenColab 中各用户角色对项目的访问控制规则。

## 角色说明

| 角色 | 说明 |
|---|---|
| `admin` | 系统管理员。对所有项目和用户拥有完全权限。 |
| `pi` | 课题负责人（Principal Investigator）。可管理所有项目。 |
| `researcher` | 实验室成员。只能访问自己拥有或被共享的项目。 |

本文档将 `admin` 和 `pi` 统称为**特权角色**。

---

## 项目可见性

| 角色 | 可见项目范围 |
|---|---|
| admin / pi | 系统中的所有项目 |
| researcher | 仅限自己是成员（owner 或 member）的项目 |

Researcher 可进一步筛选视图：
- **全部项目** — 自己拥有的 + 被共享加入的项目
- **我的项目** — 仅限自己拥有的项目

---

## 项目生命周期

### 创建

所有已登录用户（admin、pi、researcher）均可创建项目。创建者自动成为该项目的 **owner**。

### 查看（获取 / 列表）

- Admin 和 PI 可看到所有项目。
- Researcher 只能看到自己拥有或被显式共享的项目。
- 任意已登录用户均可通过 ID 获取单个项目（`GET /api/v1/projects/{id}`），无需是成员——用于深链接和跨项目引用。

### 更新（重命名 / 修改描述）

| 角色 | 可更新的项目范围 |
|---|---|
| admin / pi | 任意项目 |
| researcher | 仅限自己 **own** 的项目 |

### 归档 / 取消归档

软删除项目，数据不丢失。归档后的项目默认不出现在列表中，可随时恢复。

| 角色 | 可归档/取消归档的项目 |
|---|---|
| admin / pi | 任意项目 |
| researcher | 仅限自己 **own** 的项目 |

### 删除

永久删除项目及其所有关联数据。

| 角色 | 可删除的项目 |
|---|---|
| admin / pi | 任意项目 |
| researcher | 仅限自己 **own** 的项目 |

---

## 成员管理

项目成员列表记录每位用户在该项目中的角色：`owner`（拥有者）或 `member`（普通成员）。

### 添加成员（`POST /api/v1/projects/{id}/members`）

| 角色 | 可添加成员的项目范围 |
|---|---|
| admin / pi | 任意项目 |
| researcher | 仅限自己 **own** 的项目 |

以 `member` 身份被共享进项目的 Researcher（非 owner）不能添加其他成员。

### 移除成员（`DELETE /api/v1/projects/{id}/members/{researcher_id}`）

| 角色 | 可移除成员的项目范围 |
|---|---|
| admin / pi | 任意项目 |
| researcher | 仅限自己 **own** 的项目 |

### 退出项目（`DELETE /api/v1/projects/{id}/leave`）

以 `member` 身份加入项目的 Researcher 可以主动退出。Owner 不能退出自己的项目——需要转让所有权或删除项目。

---

## 批量操作

批量操作对每个项目单独校验权限。若用户对批量中某个项目无权操作，该项目会被跳过并计入 `failed` 列表，其余项目正常处理。

| 操作 | 接口 | 各项目权限要求 |
|---|---|---|
| 批量归档 | `POST /api/v1/projects/batch/archive` | admin/pi：任意；researcher：仅 own 的项目 |
| 批量删除 | `POST /api/v1/projects/batch/delete` | admin/pi：任意；researcher：仅 own 的项目 |
| 批量共享 | `POST /api/v1/projects/batch/share` | admin/pi：任意；researcher：仅 own 的项目 |

---

## 筛选功能

### Admin / PI

- **按 Owner 筛选** — 多选下拉框，列出所有拥有项目的用户（当前用户排在首位）
- **显示已归档** — 勾选框，将已归档项目纳入列表

### Researcher

- **范围切换** — 分段控件：「全部项目」（own + 共享）vs「我的项目」（仅 own）
- **显示已归档** — 勾选框，将已归档项目纳入列表

---

## 界面行为

- **成员对话框**中，仅当当前用户有权管理成员（admin、pi 或项目 owner）时，才显示添加成员表单和每条成员的移除按钮。
- 每个项目的**归档**、**删除**、**退出**按钮，仅在当前用户拥有对应权限时才渲染。
- 当前用户拥有的项目显示蓝色 **Owner** 标签；否则在项目名旁以灰色文字展示 owner 姓名。
- 已归档项目整体变暗（`opacity: 0.6`）并标注**已归档**标签。

| 更新项目信息 | ✓ | ✓ | ✓ | — |
| 归档 / 取消归档 | ✓ | ✓ | ✓ | — |
| 删除项目 | ✓ | ✓ | ✓ | — |
| 添加成员 | ✓ | ✓ | ✓ | — |
| 移除成员 | ✓ | ✓ | ✓ | — |
| 退出项目 | — | — | — | ✓ |
| 批量归档 / 删除 / 共享 | ✓ | ✓ | ✓（仅 own） | — |
